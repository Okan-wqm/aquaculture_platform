## 0. How to read this ledger

**Pins.** Code: origin/main 59d0c6444 (2026-10-25) for the evidence inventory, 61d594f02 (2026-10-26, about 10:15Z) for the program inventory; origin/main had already moved to 33de2433b (PR #2123 merged) when this ledger was written. **Status of the runtime (say it first in the application).** ARIA's runtime has been paused since 2026-10-16. Every figure labelled attribution `a` was recorded before that date. Nothing built since has been run by ARIA.

**Strength labels** (rule 2): PROVEN = verifiable now from the cited file or command. PARTIAL = true but n is small, one instance, own-judge labels only, or recorded and not reproduced. BUILT_NOT_MEASURED = code merged and tested, no measurement of its effect. NOT_YET = not built or not measured; the sentence is in the future tense with a criterion. FORBIDDEN = must never be written (second table).

**Tense** (rule 5): present tense only for PROVEN. PARTIAL results are written in the past tense with n. BUILT_NOT_MEASURED sentences start with "Built and tested, not yet measured". NOT_YET sentences are future tense with a measurable criterion and a `[DATE]` placeholder (see section 5: the program's gates count cycles and events, not calendar days, so no date exists in the sources; the operator must set them).

**Attribution** (rule 3): `a` = ARIA's runtime (rows ARIA's own cycles wrote to aria/state before 2026-10-16). `b` = engineering by the operator and Claude Code sessions, including measurements the session lead ran on ARIA's code or prompts (these are NOT ARIA runtime results). `c` = bookkeeping automation under ARIA's GitHub App identity (never claimed as ARIA's work). Mixed rows say which part is which.

**Evidence pointer conventions** (rule 1):

- `INV[k]` = `rows[k]` (0-based) of `/var/aqua-kampanya-ciktilari/aria-eic-2026-10/evidence-inventory-2026-10-25.json`; the same rows appear in the appendix of `evidence-inventory-2026-10-25.md` under the claim text shown in the row. `INV-M s2` = section 2 of that .md (negative results), `s4` = engineering since 2026-10-15, `s5` = what would turn a "not yet" into evidence.
- `I26 <id>` = row id in `/root/aria-handover/2026-10-21/INVENTORY-2026-10-26.md`.
- `ZOO` = `/root/aria-handover/2026-10-21/zoo/ZOO-REPORT.md`; `STD` = `.../zoo/stageD-results.md`; `ARM` = `.../zoo/arms/ARM-REPORT.md`.
- `PLAN` = `/root/aria-handover/2026-10-21/PLAN-v2.md` (gates at lines 404-413; Board B0-B7 at 322-395; principle 8 "ARIA stays paused" at line 48).
- `PROG` = `/root/aria-handover/2026-10-21/PROGRESS.md`, entry by date and time.
- `REPO` = a read-only check I ran on 2026-10-26 in `/var/aqua-saas/.worktrees/land-check` (origin/main); the command is quoted.

**Sources not independently re-derived by me** are flagged in the n/uncertainty column. I took numbers from the inventories as written; where two sources differ I say so in section 4.
