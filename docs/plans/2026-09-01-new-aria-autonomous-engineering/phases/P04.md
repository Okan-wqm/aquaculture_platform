# P04 — PR delivery and separated authorities (S25-S32)

[PLAN authority](../PLAN.md) · [GitHub contract](../authority/github-delivery.md) · Gate: `PR_OPEN`
· Merge execution kapalıdır.

## S25 — Publisher identity and lease

- **Amaç:** Least-privilege Publisher App ve provider-backed short-lived token yaşam döngüsü kurmak.
- **Teslimatlar:** Exact App/install/repo/permission manifest, one-repo explicit downgraded token
  mint, effective rules/bypass digest, expiry/revoke/readback ve isolated mount.
- **Test/negative control:** PAT/default-broad token, wrong App/install/repo/rules/bypass, direct
  base/settings/release/deploy, cross-workspace ve provider revoke denial.
- **Evidence class:** `code_proven`, `live_proven`, `operator_attested`.
- **Acceptance IDs:** `ACC-S25`, `ACC-SEP-001`.
- **Dependencies:** S24, `OP-01`.
- **Finding IDs:** `ARIA-AUDIT-017`, `019`, `059`, `076`.
- **Commit/note:** Permission/lease contract green/pushed; note provider expiry/revoke live negative
  result taşır.
- **Exit predicate:** Mode yalnız GitHub App installation token kullanır; publisher merge/bypass
  credential alamaz.

- **Test/negative control:** Crash/timeout/concurrent duplicate PR/check, wrong fork/marker/App/SHA,
  deleted/reopened/force-updated object, pagination ve ref/trailer injection.
- **Evidence class:** `code_proven`, `live_proven`.
- **Acceptance IDs:** `ACC-S26`, `ACC-REL-001`.
- **Dependencies:** S25.
- **Finding IDs:** `ARIA-AUDIT-037`, `039`, `088`.

  readback digest taşır.
- **Exit predicate:** PR gerçeği GitHub readback ile eşleşir; publisher merge endpoint'ine erişemez.
