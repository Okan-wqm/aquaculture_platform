# IEC 61131-3 Edition 3 — Programming Language Coverage

**Standard:** IEC 61131-3:2013 — *Programmable controllers — Part 3: Programming languages*.

**Component:** `suderra-agent` v1.6.0 — the edge gateway embeds a programmable control surface used by operators and system integrators to express deterministic control logic on top of the process image. Two of the five IEC 61131-3 languages are present; the remaining three are NOT-PLANNED with explicit reasoning below.

## ST static validator (`src/st_validator.rs`) guarantees

The ST validator runs today even though the runtime VM is ROADMAP Faz 3. It guarantees:

1. Lexical + syntactic conformance to IEC 61131-3 clause 7.3.
2. Scope resolution (no reference to undeclared variables).
3. Type checking at the coarse level (BOOL not auto-coerced to INT; TIME not auto-coerced to LREAL).
4. POU boundary enforcement (VAR_INPUT read-only within the POU body).
5. Function-block instantiation discipline (each instance distinct; no static global FB use).

The validator rejection path is the current "runtime" — a rejected ST source cannot land in the running config. When the Faz 3 bytecode compiler + VM arrive, the validator becomes the compiler front end with the same invariants.

## Why LD / IL / SFC are NOT-PLANNED (and will remain so)

- **LD** — ladder is a graphical dialect primarily consumed by PLC replacement tooling. Our retrofit path (Codesys / S7comm / Modbus protocol gateway under `sensorprotocols/plc_programming/`) keeps the legacy PLC in place and exposes its state through the edge gateway rather than reimplementing ladder inside the agent.
- **IL** — deprecated by IEC 61131-3 Edition 3; its grammar is frozen; the Rust compiler + type system discourages re-birthing a deprecated paradigm.
- **SFC** — superseded by the trigger + transition + conflict-resolution primitives under `src/scripting/triggers.rs` + `parallel.rs` + `conflict.rs`, which are Rust-native and composable with ST + FBD.

This is a product-posture decision, not a silent skip. The roadmap chapter records it explicitly.
