# P06 — Shadow and PR_ONLY operation (S41-S48)

[PLAN authority](../PLAN.md) · Gates: `SHADOW`, sonra `PR_ONLY` · Merge kapalıdır.

## S41 — Shadow deployment

- **Amaç:** Independent state ile production-benzeri shadow control plane kurmak; repository write yok.
- **Teslimatlar:** Runtime manifests, separate DB/object store, worker VM binding, read-only GitHub/repository credentials.
- **Test/negative control:** Shared legacy DB/state/credential, production droplet executor, foreign CWD ve any write permission.
- **Evidence class:** `live_proven`, `operator_attested`.
- **Acceptance IDs:** `ACC-S41`, `ACC-ISO-001`.
- **Dependencies:** S40, `OP-02`, `OP-04`.
- **Finding IDs:** `ARIA-AUDIT-041`, `053`, `072`.
- **Commit/note:** Deployment checks green/pushed; note runtime identities, state endpoints digests ve zero-write probe taşır.
- **Exit predicate:** Shadow kendi durable state'iyle işler ve hiçbir legacy/repository write capability taşımaz.

- **Teslimatlar:** One-way adapter, source SHA/digest, normalized comparison metrics ve unavailable result.
- **Test/negative control:** Legacy import/runtime fallback, shared write/credential, mutable live path ve comparison-driven authority grant.
- **Evidence class:** `code_proven`, `live_proven`.
- **Acceptance IDs:** `ACC-S42`, `ACC-ISO-001`.
- **Dependencies:** S41.
- **Finding IDs:** `ARIA-AUDIT-037`, `038`, `067`, `072`.

- **Exit predicate:** Adapter yokluğu yeni truth'ü bozmaz; legacy sonucu approval/evidence authority değildir.
