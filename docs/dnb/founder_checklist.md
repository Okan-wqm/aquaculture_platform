    - Kendi incelemelerimiz 28 açık sorun buldu, 3'ü kritik. Bu sayıları slayta koyma, soru gelirse söyle.
    - Grant ve plan 036/037 çalışmaları şu an yalnız bu oturumun yerel branch'lerinde. Uzak branch'e push sürüyor; bitene kadar kaybolma riski var.
    - Dikkat: ARIA'nın GitHub App kimliğiyle 36 kayıt-tutma (bookkeeping) PR'ı açıldı. Bunlar kod değil. 26 Eylül'den beri bu iş akışı kendi PR'ı için otomatik merge (auto-merge) de istiyor (#1669). "ARIA 0 PR açtı" derken bunu ekle: "ARIA'nın düşünen çekirdeği 0 kod PR'ı açtı".
