# P06 — Shadow and PR_ONLY operation (S41-S48)

[PLAN authority](../PLAN.md) · [Gate/operations authority](../authority/operations-reliability.md) ·
Gates: `SHADOW`, sonra `PR_ONLY` · Merge kapalıdır.

## S41 — Shadow deployment

- **Amaç:** Clean-room predeploy ile independent state üzerinde production-benzeri shadow control
  plane kurmak; repository write yok.
- **Teslimatlar:** Runtime manifests, separate DB/object store, dedicated control/worker VM ve
  per-role UID/resource/network binding, read-only GitHub/repository credentials, paging/kill ve
  aggregate capacity admission.
- **Test/negative control:** Shared legacy DB/state/credential, production droplet executor, shared
  UID/secret/mount, foreign CWD, paging/kill kaybı, headroom aşımı ve any write permission.
- **Evidence class:** `live_proven`, `operator_attested`.
- **Acceptance IDs:** `ACC-S41`, `ACC-ISO-001`.
- **Dependencies:** S40, `OP-02`, `OP-04`, `OP-06`, `OP-07`.
- **Finding IDs:** `ARIA-AUDIT-041`, `053`, `072`.
- **Commit/note:** Deployment checks green/pushed; note runtime identities, state endpoints digests
  ve zero-write probe taşır.
- **Exit predicate:** Shadow kendi durable state'iyle işler ve hiçbir legacy/repository write
  capability taşımaz.

  mission routing, out-of-band operator freeze/page ve teardown proof.
- **Test/negative control:** Merge endpoint/token/permit, hidden direct git push beyond mission
  branch, mode escalation ve policy self-write.
- **Evidence class:** `live_proven`, `operator_attested`.
- **Acceptance IDs:** `ACC-S43`, `ACC-REL-001`, `ACC-TCB-001`.

  general live dispatch effect'i oluşturamaz.
