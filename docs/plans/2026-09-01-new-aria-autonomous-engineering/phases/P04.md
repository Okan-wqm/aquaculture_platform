# P04 — PR delivery and separated authorities (S25-S32)

[PLAN authority](../PLAN.md) · Gate: `PR_OPEN` · Merge execution kapalıdır.

## S25 — Publisher identity and lease

- **Amaç:** Least-privilege Publisher App ve provider-backed short-lived token yaşam döngüsü kurmak.
- **Teslimatlar:** App permission manifest, token mint/expiry/revoke, durable lease ve broker-free secret mount.
- **Test/negative control:** Operator PAT, modeled-only TTL/revoke, expired/revoked token, cross-workspace use ve linked-worktree signing bypass.
- **Evidence class:** `code_proven`, `live_proven`, `operator_attested`.
- **Acceptance IDs:** `ACC-S25`, `ACC-SEP-001`.
- **Dependencies:** S24, `OP-01`.
- **Finding IDs:** `ARIA-AUDIT-017`, `019`, `059`.
- **Commit/note:** Permission/lease contract green/pushed; note provider expiry/revoke live negative result taşır.
- **Exit predicate:** Mode yalnız GitHub App installation token kullanır; publisher merge/bypass credential alamaz.

## S26 — PR/check reconciliation

- **Amaç:** Branch/PR/check create-update-reconcile etkilerini merge yetkisi olmadan durable yapmak.
- **Teslimatlar:** UUID effects, idempotency, exact head/base, read-after-write ve reconciliation cursor.
- **Test/negative control:** Timeout/retry duplicate PR, stale head, unreachable status, forged merge claim ve commit ref/trailer injection.
- **Evidence class:** `code_proven`, `live_proven`.
- **Acceptance IDs:** `ACC-S26`, `ACC-REL-001`.
- **Dependencies:** S25.
- **Finding IDs:** `ARIA-AUDIT-037`, `039`, `088`.
- **Commit/note:** GitHub sandbox/live contract green/pushed; note PR identity, reviewed head ve readback digest taşır.
- **Exit predicate:** PR gerçeği GitHub readback ile eşleşir; publisher merge endpoint'ine erişemez.
