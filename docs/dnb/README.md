# DNB NXT Accelerator application: ARIA

ARIA's application pack for the Startuplab Accelerator run in partnership with DNB (DNB NXT). ARIA is a planned spin-off of SUDERRA AS and is not yet incorporated.

| File                    | What it is                                                                                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `application.submit.md` | The text to enter in the application form. Instructions for the assistant who fills it in come first.                                                  |
| `deck.final.md`         | A slide-by-slide specification of the pitch deck, for a design tool.                                                                                   |
| `market_2026.md`        | 2026 market figures, each with its source page. Every figure must be opened and confirmed before use.                                                  |
| `market.md`             | Earlier market research (2025 figures) with sources and grades.                                                                                        |
| `application.final.md`  | The same answers with the founders' check notes and alternatives (not for pasting).                                                                    |
| `founder_checklist.md`  | The founders' checklist before submitting (Turkish). One security item is withheld in this public copy.                                                |
| `what_not_to_say.md`    | Claims that must not appear in the application, the deck or a live pitch, each with a true alternative.                                                |
| `evidence.md`           | The evidence base: facts E-001 to E-082, each with its source in the repository, as of 26 Sep 2026. One security item is withheld in this public copy. |

These rules hold throughout:

- Every figure comes from the repository's own records or from a named public source.
- `[TO FILL]` marks what only the founders can supply.
- `[verify]` marks a public figure that must be checked on its source page.
