All documentation and user guides must be written in English, not Turkish.

**Why:** The platform documentation needs to be accessible to international users and must be simple enough that anyone — regardless of technical background — can follow it.

**How to apply:** When writing user manuals, guides, or tutorials:
- Use simple, plain English
- Assume zero technical knowledge
- Step-by-step with numbered instructions
- Avoid jargon — explain every term on first use
- Use visual descriptions and examples
- "Click this → see that → do this next" format
