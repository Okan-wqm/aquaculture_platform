## Lead conflict rulings (first-hand verified)

1. **`tenantUsers` existence.** messaging-expert claimed "no resolver anywhere → 400". **WRONG** — it scanned only messaging-service. Verified: `tenantUsers` exists in auth-service (`apps/auth-service/src/modules/tenant/resolvers/tenant.resolver.ts:174`) gated by `@TenantAdminOrHigher()`. Real defect (`MSG-HIGH-051`): an OPERATOR/MODULE_USER (the typical field worker) gets `Forbidden`, so New Chat picker is empty for normal users. Not a missing query.
2. **Feeding enum casing.** form-write-auditor marked `recordDailyFeeding` PASS; mobile-app-auditor marked it always-400. **mobile-app-auditor CORRECT** — verified: `registerEnumType(FeedingMethod, {name})` with no `valuesMap` exposes the enum KEYS (`MANUAL`…) in the SDL; mobile sends the enum VALUE `'manual'` → GraphQL coercion rejects → 400 (`FARM-HIGH-050`). Control proof: `clockIn` works because mobile correctly sends the KEY `'MOBILE'`. Mortality/cull work because they send uppercase KEYs.

## Verified SOUND (recorded so they are not re-flagged)

- **RS256 key SSoT** — auth-service signs (`JWT_PRIVATE_KEY`), all verifiers use one `getJwtVerifyOptions()` pinned `algorithms:['RS256']`; JWKS rotation; `tests/invariants/jwt-rs256-only.spec.ts` bans HS256. The `authenticated-fetch.ts:138` "HS256" string is a comment only.
- **Backend tenant trust anchor** — JWT claim preferred over `x-tenant-id`; `StripInternalHeadersMiddleware` strips the header; HMAC binds tenant. Mobile sending `X-Tenant-Id` grants no cross-tenant access.
- **Offline queue/cache tenant partitioning** — `pending_${tenantId}_${id}`, `cache_${tenantId}:${key}`, AES-GCM at rest, key reset on full wipe.
- **Mortality/cull** atomic single-tx decrement + over-decrement guard + idempotency *when envelope present* (`farm_mobile_command_receipts`).
- **Messaging idempotent send** (Redis+Postgres ledger), channel-membership authz, cross-tenant member-add block. **Media upload path** (presigned PUT, MIME allowlist, tenant-prefix, HeadObject).
- **HR self-service** (clockIn/leave self-scope), **leave FSM**, **attendance guards**, global **RolesGuard** fail-closed.
