# IEC 62443-4-2 — Component Security Gap Table

**Standard:** IEC 62443-4-2:2019 — *Security for industrial automation and control systems — Part 4-2: Technical security requirements for IACS components*.

**Component class:** Embedded Device Component (EDC) — Rust edge gateway running on ARMv7 / aarch64 Linux with mTLS-only cloud uplink, OT-side protocol termination (Modbus-TCP/RTU, OPC UA, S7comm, EtherNet/IP, ADS, Codesys, LoRaWAN, I2C, Atlas EZO, GPIO/PWM).

**Target security levels:**

- **SL2 baseline** for the entire device — the platform posture claimed publicly as "SL1 self-declaration today, SL2 roadmap certification in 6 months".
- **SL3 for life-safety outputs** — digital outputs, pH / NH3 threshold actuation, dosing pumps, aerator control, VFD setpoints. The life-safety subset uses additional controls (multi-party authorization for high-severity setpoints, signed actuator class binding per ADR-024, HMAC-chained audit per ADR-020) because a single-actuator failure is regulated water-quality / animal-welfare exposure, not just operational inconvenience.

No component in this device is claimed SL4. A claim to SL4 requires defence against nation-state adversaries with physical access to the device — outside the design envelope for a farm-floor edge gateway.

## Summary

- **SL2 baseline blockers (count: 5):**
  1. FR1 CR 1.1 RE(1) — local-console MFA (operator PIN + cert) — ROADMAP-Q3.
  2. FR3 CR 3.4 — OTA firmware signing runtime enforcement (ORPHAN-EDGE-018) — ROADMAP-Q3.
  3. FR5 — zone-conduit documentation produced by `architecture-writer` — ROADMAP-Q2.
  4. FR6 CR 6.2 — cloud-side audit runtime sink (ORPHAN-EDGE-004) — ROADMAP-Q2, pre-requisite for SOC 2 Type II as well.
  5. FR7 CR 7.3 — automated backup-restore verification runbook — ROADMAP-Q3.

- **SL3 (life-safety outputs) additional blockers (count: 6):**
  1. FR1 — multi-party authorization (ADR-024 §4 two-person rule for `ActuatorWrite:High`).
  2. FR2 — operator / supervisor dual-signature non-repudiation.
  3. FR3 — boot-time binary signature verification (paired with ORPHAN-EDGE-018).
  4. FR3 CR 3.8 — session-nonce replay window.
  5. FR4 CR 4.1 RE(1) — side-channel resistance attestation document.
  6. FR7 CR 7.1 RE(1) — hardware-side DoS protection for life-safety channels (ADR-023 SL3 path).

## SL certification path

- **Today (2026-04-24):** SL1 self-declaration. No "SL2 certified" or "SL3 certified" claim is made in any customer-facing collateral; the certification artefact file under `docs/compliance/certificates/` does not exist.
- **6 months out:** IEC 62443-4-2 SL2 certification via TÜV SÜD or Exida. Blockers above must land first. See [certifications-roadmap.md](./certifications-roadmap.md).
- **18 months out:** IEC 62443-4-2 SL3 for the life-safety-actuation subset of requirements per ADR-023.
