## S09 — Portable onboarding identity

- **Amaç:** S04 canonical resolver'ını portable provider onboarding adapter'larına bağlamak.
- **Teslimatlar:** Typed code/state/authority repo roles, configured base ref, mutable alias
  metadata, base/head/fork/installation lifecycle ve onboarding manifest.
- **Test/negative control:** Clone/path/custom/no-origin, fork/cross-provider collision,
  rename/transfer/delete-recreate, install suspend/reinstall, foreign CWD ve path leak.
- **Evidence class:** `code_proven`.
- **Acceptance IDs:** `ACC-S09`, `ACC-ISO-001`.
- **Dependencies:** S08.
- **Finding IDs:** `ARIA-AUDIT-049`–`051`, `053`, `060`.
- **Commit/note:** Identity fixtures green/pushed; note canonical IDs ve source SHA'yı kaydeder.
- **Exit predicate:** Kimlik mutable path/CWD'ye bağlı değildir; collision ve split negatifleri
  reddedilir.
