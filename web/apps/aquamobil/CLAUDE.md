# aquamobil — CLAUDE.md (standalone offline-first PWA)

> Root rules in `/CLAUDE.md` apply; `web/CLAUDE.md` (Module Federation) does NOT — aquamobil is a STANDALONE Vite app, not a federated remote. This file is its authority.

Field-worker mobile data-entry PWA. `base: '/mobile/'`, own toolchain + standalone lockfile + own `node_modules`, dev port 8090 (`web/apps/aquamobil/vite.config.ts`). React 19; the UI vocabulary is the app's own `src/components/ui` primitives (Field/Input/Select/Textarea, Switch, Button, ListRow, BottomSheet, IconButton, PageHeader) — no UI-kit dependency (FE-MEDIUM-091). The Docker build context is the REPO ROOT, not the app dir — `infrastructure/docker/Dockerfile.aquamobil` copies `libs/farm-shared` and `libs/shared-contracts` from outside the app; only the builder WORKDIR and the lockfile install are app-scoped.

## Invariants

- **Design tokens are the SSoT for colour, type and touch density:** `src/styles/tokens.css` declares three themes (`night` / `day` / `colour`) as CSS custom properties selected by `<html data-theme>`, plus two touch densities under `<html data-density>`. Tailwind maps them to semantic utilities (`bg-surface-1`, `text-ink-2`, `border-line`, `bg-acc`, `text-type-mortality`, `h-tap-key`) — write ONE class, never a `dark:` pair. Applied by `src/hooks/useTheme.ts` + `src/hooks/useDensity.ts`, pre-painted by the external `public/theme-init.js` (the production CSP blocks inline scripts; keep all three in step). The browser-chrome colour per theme is each theme's `--bg-solid`, which `vite.config.ts` reads from `tokens.css` into the `data-theme-color-*` attributes of `index.html` — no hex lives in TS. `dark:` variants, the legacy `ocean`/`sea`/`coral` palettes and stock gray ramps are banned outright by `src/__tests__/design-token.invariant.spec.ts`, which also enforces theme and density parity. Geist is self-hosted in `public/fonts/` because `font-src 'self'` in the nginx CSP blocks font CDNs outright.
- **PWA service worker:** `vite-plugin-pwa` in `injectManifest` mode — the DEPLOYED SW is the HAND-WRITTEN `web/apps/aquamobil/src/pwa/messaging-sw.ts` (FE-CRITICAL-050-SW). It owns offline sync, `notificationclick`, and LOGOUT handlers plus the precache manifest. Do NOT switch to `generateSW` (it drops those handlers).
- **Strings and brand come from shared-ui through two narrow source aliases:** `@aquaculture/shared-ui/i18n` (the single message catalog + `I18nProvider`) and `@aquaculture/shared-ui/brand` (vite, vitest and tsconfig declare both; the Dockerfile copies exactly those two paths). Never import the shared-ui package root — the standalone build context does not carry it.
- **Tenant query keys are a MIRROR that has already DRIFTED:** aquamobil does not import the rest of `@aquaculture/shared-ui` (deliberate — standalone lockfile, offline-first), so `createTenantQueryKey` is hand-maintained at `web/apps/aquamobil/src/utils/tenant-query-keys.ts`. The tenant-prefix contract `['tenant', tenantId, …]` DOES hold in both, so there is no cross-tenant leak (FE-CRITICAL-014/015/016). The two are NOT identical: `web/shared-ui/src/utils/tenant-query-keys.ts` appends `sessionEpochSegment()` (#687, ORPHAN-MEDIUM-200 — fresh cache on tenant re-entry) and the aquamobil mirror has no epoch segment, so it still serves stale cache after tenant re-entry. That gap is open; the file's own "Mirrors … verbatim" header comment is wrong too. Do not trust either file's claim of equality — diff them.
- **React dedupe:** `libs/farm-shared` is aliased (not npm-installed); `vite.config.ts` sets `dedupe: ['react','react-dom']` to force a single React copy across the aliased boundary (Tier-1 "make it impossible").

## Enforcement

`npm test` (`vitest run`, inferred Nx `test` target) runs every `src/**/*.spec.{ts,tsx}` — the SW build-artifact invariant included — on every affected PR (`ci-affected.yml`) and under coverage in `ci-full.yml`; the LCOV report is inventoried in `tools/quality/coverage-report-inventory.json`. `test:invariant` additionally runs the SW build-artifact spec on its own (a real `vite build`) so the artifact gate is selectable without the whole suite. Both targets are kept reachable by `tests/invariants/test-target-ci-reachability.spec.ts`; until a plain `test` script existed the whole suite was unselectable and ran nowhere (INFRA-HIGH-157 / FARM-MEDIUM-304). Its GraphQL contract is generated end to end — every document under `src/**` (the offline-queue registry included) is a codegen source, `graphqlRequest` takes only a `TypedDocumentNode`, and the queued payload / view types derive from `src/generated/graphql.ts`; `tests/invariants/aquamobil-graphql-contract-ssot.spec.ts` keeps a hand-written `*Input` mirror or an untyped overload from coming back (MOB-HIGH-022). NOTE: the `eslint src` lint baseline is large and pre-existing (ORPHAN-MEDIUM-112) — do not treat it as a clean gate.
