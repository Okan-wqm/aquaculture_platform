## Systemic Patterns
- Tenant isolation gaps remain the dominant cross-cutting defect class. Current-cycle examples include gateway tenant resolution, messaging conversation ownership, messaging write paths dropping `tenantId`, front-end offline cache namespacing, tenant provisioning becoming `ACTIVE` too early, CQRS lacking a request envelope, and tenant identity drift in entity modeling. This is a repeat of the 2026-04-09 compaction pattern and remains unresolved.
- Fail-open or permissive fallback behavior is recurring in security-sensitive paths. Current-cycle examples include event-bus startup continuing when NATS is down, AI quota counters falling back to in-memory state when Redis is absent, notification webhook encryption deriving a deterministic dev key, MCP degraded mode still advertising the full catalog, and supply-chain/deploy surfaces relying on mutable tags or incomplete scan coverage.
- Exactness and replayability are still eroding in persisted operational state. Current-cycle examples include hydroponics math using native `number`, sensor/VFD schema values using floating point, `message_receipts` uniqueness being partition-dependent, batch-close argument ordering corrupting audit metadata, and restore paths ignoring the requested target schema.
