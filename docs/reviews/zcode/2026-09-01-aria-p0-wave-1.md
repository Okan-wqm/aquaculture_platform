# ARIA P0 fix wave 1 — seven audit findings closed

**Date:** 2026-09-01 · **Agent:** zcode · **Cycle:** 2026-09-01 advisory-gate-recovery
**Source audit:** `docs/reviews/2026-09-01-aria-full-system-audit.md` (88 findings; 24 P0);
its English verification note is `docs/reviews/codex/2026-09-01-aria-full-system-audit.md`.
Each fix below was validated against the audit's file:line citations before implementation, and each
carries a regression test that fails on the pre-fix code. Registry finding IDs + `Closes:` trailers
are registered after the parallel registry PRs merge (hash-chained ledger, sequential-PR rule).

## ARIA-AUDIT-085 — one secret policy, correct regex

`artifact_safety.SECRET_PATTERNS` carried `r"...=\\S+"` — a literal backslash-S — so
`OPENAI_API_KEY=...` and `ARIA_LEASE_TOKEN=...` passed through executor artifacts unredacted, and it
had drifted from `secret_scrub`'s separate pattern set. The compiled patterns now live once, in
`secret_scrub._SECRET_PATTERNS` (extended with the artifact-side families: `named_env_assignment`
with the corrected `\S+`, `github_token_family`, `generic_sk_key`), exposed via `secret_patterns()`,
and consumed by `artifact_safety` under its existing contract. Tests pin BOTH consumers to the same
set and replay the audit's exact leak strings.

## ARIA-AUDIT-001 — the maintenance lane runs the one canonical compactor

The lane's inline heredoc compactor silently skipped malformed lines, rewrote ledgers without re-
chaining the hash chain, archived nothing pristine, and pushed green. The workflow step now calls
`python3 -m aria_kernel state compact --tools-dir … --retain-days …` only. The hot-artifact and
discovery-FATES cleanup the heredoc owned moved INTO `state_compact.compact_state` (cycle-stamp
parsing with mtime fallback; 30-day FATES clock), with dry-run support, governance recording, and
tests. The next cron (15:13 UTC) runs the kernel path.

## ARIA-AUDIT-044 — the unit-interval gate at every confidence site

`confidence.confidence_in_unit_interval` already rejected bool/NaN/out-of-range; three sites
reimplemented it worse. `record_operator_feedback` (NaN slipped `nan < 0`/`nan > 1`; `True` passed
isinstance), the consensus mean (isinstance-only filter), and the judge bridge's envelope path now
all call the one gate.

## ARIA-AUDIT-027 — watchdog Gate-B fails closed

`measure_watchdog_fp_rate` reported a pristine 0.0 (and passed) for an absent findings tree, an
empty window, silently skipped unreadable findings, and counted timestamp-less rows into the
denominator. Every unmeasurable shape now returns `status: "unmeasured"`, `gate_passes: false`, an
explicit reason, and the CLI exits 1 by default (the opt-in `--exit-on-fail` flag is gone — it made
fail-open the default).

## ARIA-AUDIT-033 / 034 — adapter failure is typed, never clean

- Banned-phrase adapter: a non-zero child exit with no parseable violations (127 missing CLI, 2 gate
  error) now returns `status: "unavailable"`, the child's exit code, and a non-zero process exit — a
  dead scanner no longer reads as "no banned phrases".
- Outbox adapter: unreadable in-scope sources are counted and surfaced; the envelope carries
  `status: "incomplete"` plus `unreadable_paths` instead of silently shrinking the scan.

## ARIA-AUDIT-055 — glob evidence verifies every match

`_glob_repo_verified` graded the whole glob from the first five sorted matches, letting an
uncommitted sixth file ride a `repo_glob_verified`. All matches must now resolve as committed blobs
at the baseline SHA; a glob with more matches than the 500-file verification ceiling grades
`glob_too_large_to_verify` (insufficient evidence) — never verified-by-sample. Regression test
replays the audit's six-match reproduction.

## ARIA-AUDIT-079 — transport acceptance is not a semantic verdict

`review_runner` returned `verdict="no_gaps"` for any accepted, role-bound result row without reading
a word the judge wrote. The runner now loads the sealed output artifact at the row's `output_path`,
re-verifies its content hash, and requires an explicit `VERDICT: no_gaps` line. Missing artifact,
hash drift, no verdict line, or a `gaps_open` verdict all block auto-merge as `gaps_open` with a
named gap. The I-GATE-03 pin was rewritten to the new contract (its fixture now seeds a real sealed
payload), and four fail-closed regression tests cover the audit's reproduction shapes.

## Hot-fix — phantom pathspecs made every publish fatal after the ACK landed

With the continuity gate finally ACK-passing, the executor's publish died at
transport: `git add --all --force -- <predecessor surfaces>` went fatal on
`pathspec 'tools/run-artifacts/hot/…' did not match any files` — the 2026-08-31
surgery's declared-but-tree-absent hot artifacts. `_staged_pathspecs` includes
the predecessor's declared paths so vanished surfaces stage as deletions, but
a pathspec matching neither worktree nor index is FATAL to `git add`.
`_stageable_pathspecs` now drops matchless specs (nothing to add, nothing to
delete), letting the fresh snapshot stop declaring the phantoms and healing
the branch. RED reproduced the production error byte-for-byte in
`test_ack_publish_stages_past_a_predecessor_surface_absent_everywhere`;
GREEN passes with the full 87-test state_store suite intact.
